## Objectives

- Analyze algorithms and their complexity using mathematical techniques.
- Develop data structures in C++: abstract data types, linked lists, stacks, queues, trees, and graphs.
- Implement algorithms and conduct real-system performance measurements and analyses.
- Contribute to SDG 9: Industry, Innovation, and Infrastructure.

## Course Intended Learning Outcomes (CILO)

| Code   | Outcome                                                                                                          |
| ------ | ---------------------------------------------------------------------------------------------------------------- |
| CILO 1 | Apply fundamental data structures and techniques to solve engineering-related problems through algorithm design. |
| CILO 2 | Design efficient algorithms and analyze their complexity.                                                        |
| CILO 3 | Build efficient algorithms based on selected data structures using good programming styles in C++.              |
